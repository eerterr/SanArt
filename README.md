# SonArt
Веб-дашборд для анализа Big Data в учреждениях культуры.  Система объединяет данные о посещаемости, обратной связи и вовлечённости аудитории, визуализирует ключевые показатели, сегментирует посетителей с помощью кластеризации и формирует рекомендации по планированию культурных мероприятий.

## Как запустить локально

Бэкенд (Flask + SQLite, простая база — собирается из `data/*.csv`):

```bash
cd Backend
pip install -r requirements.txt
python app.py
```

Поднимется на `http://localhost:5000`. Первый запуск сам соберёт `DB_section/sanart.db`
из CSV в `data/` (реальные `institutions_official` + синтетика для демо).

Фронтенд (статические файлы, отдельным сервером):

```bash
cd Frontend
python -m http.server 8080
```

Открыть `http://localhost:8080/login.html`.

Подробности по фронтенду — в `Frontend/README.md`.
